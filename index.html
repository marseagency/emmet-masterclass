Emmet در VS Code

ببین رفیق، تا حالا شده از نوشتن تگ‌های باز و بسته HTML خسته بشی؟ امروز می‌خوام یه ورد جادویی بهت یاد بدم. تو VS Code فقط یه فرمول کوتاه می‌نویسی، دکمه Tab رو می‌زنی و بوم! صفحه وبِت ساخته میشه.

قانون طلایی و تخطی‌ناپذیر Emmet:

توی فرمول‌هایی که می‌نویسی، هیچ‌وقتِ هیچ‌وقت نباید «فاصله» (Space) بذاری! (مگر اینکه داری متن داخل سایت رو مینویسی).

مرحله ۱: روابط خانوادگی مرحله ۲: آرایش تگ‌ها مرحله ۳: دستگاه کپی مرحله ۴: گروه‌بندی مرحله ۵: ترفندهای مخفی غول مرحله آخر
۱

روابط خانوادگی تگ‌ها (پایه‌ریزی)

تگ ساده

هیچ کار عجیبی لازم نیست. فقط اسم تگ رو بنویس و Tab بزن. خودش باز و بسته‌اش می‌کنه.

h1
<h1></h1>

رفتن به دلِ تگ (فرزند) >

وقتی می‌خوای یه تگ، داخل یه تگ دیگه باشه (مثل پاراگرافی که تو یه باکسه)، از علامت بزرگتر استفاده کن.

div>p
<div> <p></p> </div>

کنار هم چیدن (خواهر و برادر) +

وقتی می‌خوای دو تا تگ هم‌سطح و کنار هم باشن، با مثبت به هم وصلشون کن.

h1+p+button
<h1></h1> <p></p> <button></button>

بالا کشیدن خودمون (خروج از فرزند) ^

فرض کن رفتی داخل یه تگ، حالا می‌خوای بیای بیرون و تگ بعدی رو کنار پدرش بسازی! با این علامت یه پله میای بالا.

div>p>span^h2
<div> <p> <span></span> </p> <h2></h2> </div>
۲

هویت دادن (آرایش کردن تگ‌ها)

دادن کلاس .

دقیقاً مثل CSS! اسم تگ رو بنویس، یه نقطه بذار و اسم کلاس رو تایپ کن.

p.text-red
<p class="text-red"></p>

دادن آیدی (ID) #

اینم مثل CSS کار می‌کنه. با هشتگ آیدی بده. (حتی می‌تونی همزمان کلاس و آیدی هم بدی: h1#title.bold)

div#header
<div id="header"></div>

نوشتن متن داخل تگ { }

می‌خوای دکمه‌ات متن داشته باشه؟ متنت رو بذار تو آکولاد. (تنها جایی که اجازه داری Space بزنی همینجاست!)

button{کلیک کن داداش}
<button>کلیک کن داداش</button>

دادن صفت‌های خاص (Attribute) [ ]

برای چیزایی مثل لینک عکس (src) یا آدرس لینک (href) از کروشه استفاده می‌کنیم.

a[href="google.com" target="_blank"]
<a href="google.com" target="_blank"></a>
۳

دستگاه کپی و شماره‌گذاری

تکثیر کردن *

می‌خوای ۵ تا آیتم لیست بسازی؟ الکی کپی پیست نکن. ضربدر ۵ کن!

ul>li*3
<ul> <li></li> <li></li> <li></li> </ul>

شماره‌گذاری خودکار $

وقتی تگ‌ها رو تکثیر می‌کنی، با علامت دلار ($) بهش بگو خودش شماره‌ها رو به ترتیب بندازه.

نکته خفن: اگه $$ بذاری، شماره‌ها رو 01, 02 می‌زنه. اگه $@- بذاری برعکس می‌شمره!

ul>li.item-$*3{آیتم $}
<ul> <li class="item-1">آیتم 1</li> <li class="item-2">آیتم 2</li> <li class="item-3">آیتم 3</li> </ul>
۴

گروه‌بندی (راز صفحات بزرگ)

دسته‌بندی با پرانتز ( )

گاهی استفاده از ^ (برگشت به بالا) خیلی گیج‌کننده میشه. بهترین کار اینه که هدر، بدنه و فوتر رو تو پرانتزهای جدا بذاری و با + بهم وصل کنی. اینجوری فرمولت خیلی تمیزتر میشه.

(header>h1) + (main>p) + (footer>span)
<header> <h1></h1> </header> <main> <p></p> </main> <footer> <span></span> </footer>
۵

هوش مصنوعی امت و ترفندهای مخفی

ساختار اولیه HTML !

تو یه فایل خالی HTML فقط یه علامت تعجب بزن و Tab رو فشار بده. کل استخوان‌بندی صفحه (head و body) ساخته میشه!

!

تگ‌های نامرئی (پیش‌فرض‌ها)

اگه تگی ننویسی و فقط کلاس بدی، امت برات div می‌سازه. از اون خفن‌تر: اگه تو یه لیست (ul) کلاس خالی بدی، خودش می‌فهمه باید li بسازه!

.box + ul>.item*2
<div class="box"></div> <ul> <li class="item"></li> <li class="item"></li> </ul>

تولید متن الکی lorem

طراحی که بدون متن نمیشه. بنویس lorem تا یه پاراگراف طولانی بهت بده. اگه نوشتی lorem5 فقط ۵ تا کلمه بهت میده!

p>lorem4
<p>Lorem ipsum dolor sit.</p>

غول مرحله آخر

حالا که همه چی رو یاد گرفتی، بیا کل یه صفحه شامل هدر (با منو)، بخش اصلی (با ۳ تا مقاله) و فوتر رو فقط تو یک خط کد بسازیم!

(header>nav>ul>li*3>a[href="#"]{لینک $})+(main>section.hero>h1{خوش آمدید}+p>lorem8)+(section.articles>div.card*3>h2{مقاله $}+img[src="pic.jpg"]+p>lorem10)+(footer>p{کپی رایت})

کد بالا رو کپی کن، بنداز تو VS Code، کرسر موس رو ببر دقیقاً آخر خط و Tab رو بزن. خودت معجزه رو ببین!
